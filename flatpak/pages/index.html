Helium Flatpak

Unofficial package for x86_64 and aarch64 Linux

Helium runs on your host system. Flatpak handles installation, updates, and the app menu entry. Your browser profile stays separate from a native Helium install.

Install Helium

Accept the prompt to add the Helium repository for updates and to keep the app available to reinstall after uninstalling.

Or install Helium system-wide from a terminal:

flatpak install --system https://helium.thomasberrios.com/net.imput.helium.flatpakref

You can also add the repository separately and install Helium later from your software store.

Source and release notes are available on GitHub.
